# Practical-7: Advanced Media Player Application

**Student Enrollment Number:** 24012011120  
**Course:** Mobile Application Development (MAD)  
**IDE:** Android Studio  

## Aim
Create an Android Media Player application with full playback control options (Play, Stop, Next, Previous, Shuffle) and custom UI design.

## Description
This practical implements an advanced music player with playback controls, custom album art display (poster.png), and background service integration.

## Features
- Custom Media Player Interface with album art (poster.png).
- Controls: Play, Stop, Next, Previous, Shuffle.
- Background MusicService.kt managing audio playback (song.mp3).
